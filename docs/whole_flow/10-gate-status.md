# Gate status

The council record's gates are its own
(`council/records/2026-11-17-g3-whole-flow-cases.md`, WF1 to WF13); this
section only records, with dates, what the repository can show about them.

Each gate with something to record has its own file, `gates/WF<NN>.md`
(two digits, the gate's own text first), so pull requests on different gates
never edit the same file; the folder is the list, with no index lines to
collide. A gate with no file has nothing recorded here yet.
