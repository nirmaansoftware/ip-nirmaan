# Whole-flow cases (G3, M87)

Source: `council/records/2026-11-17-g3-whole-flow-cases.md` (gates WF1 to
WF19, with its two addenda of 2026-11-18), which applies decision 6 of the
pilot retrospective
(`council/records/2026-11-14-pilot-retrospective.md`). A whole-flow trial puts
a request in, seats every work stage with the model, and judges only the final
block. It credits no skill and no level.

The record splits the build into pull requests. This document is the index:
each part is its own file in `docs/whole_flow/`, so parallel pull requests
edit different files instead of conflicting in one. A pull request edits only
the parts it changes; a new part is a new numbered file and one line here.
Gate status is one file per gate (`docs/whole_flow/gates/WF<NN>.md`).
