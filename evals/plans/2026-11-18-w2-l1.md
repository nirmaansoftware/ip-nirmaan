# W2-L1: the live evidence batch plan

This file publishes the plan of the W2-L1 live evidence batch: its cases, the
counts fixed before the first trial, the slot order and the read. The plan was
written before the run (2026-11-17) and its slot list was fixed before trial 1
(2026-11-18 16:32Z); the batch driver refuses to change a count once any slot
has started. It is committed after the run so that every record pull request
can cite one list of the whole batch. Nothing in it was changed after an
outcome was seen.

## What ran

- Harness: the default harness (attempts-3, the default since ip#347),
  fingerprint `sha256:0ef27db15df3066826c1eb942c46ad42ade809b1a71ebd4d39d8c37d793bca00`
  with knowledge documents and
  `sha256:9aa7a333cd961a23aa919616fac6428f9f29fed1ba44b2fa3f5c6ee49e745d39`
  without, on `main` 01adfe9, Claude Code 2.1.325, seat model
  claude-opus-5-5, `--purpose evidence`, one trial per record.
- Arm E: knowledge documents on. These trials are the evidence of the read.
- Arm N: `--without-knowledge`, labelled knowledge off. It never counts toward
  a level; it is reported beside the read only.

## Slot order

Eight rounds. Each round runs every case once on arm E, in a base order that
mixes RTL and verification cases, starting 3 places later each round, so that a
stop or a time-of-day effect does not land on one case. Arm N slots sit at the
ends of the rounds. A slot was marked attempted before its trial started.

## Stop rules

- A trial that returns no model answer (a plan or usage limit) stops the
  driver at once. That trial is committed as failed and never run again
  (decision 11 of the pilot retrospective; council record
  2026-11-15-pilot-topup-reruns). One such trial happened: slot 57 (arm N).
- An interrupted or killed trial is failed and never run again.
- No top-up, no extension, no replacement, no second read.

## The read

Once, after every one of the 153 records has merged: `scripts/capability_levels.py`
on `main`, then per skill and group n, passes, the Wilson interval and the
level. A skill is Practised when its counted group has n of at least 5 and a
Wilson lower bound of at least 0.5 (`docs/CAPABILITY_LEVELS.md`). Any level
that `capability/levels.json` shows while only part of the batch is merged is
an interim figure and is never cited.
